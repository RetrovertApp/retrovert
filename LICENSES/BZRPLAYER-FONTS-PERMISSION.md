# BZRPlayer font redistribution permission

- Grantor: BZRPlayer project (`aargirakis/BZRPlayer`)
- Recipient: Replay/Retrovert project
- Permission recorded: 2026-08-13
- Source faces: `Protracker 1.0.png` and `Protracker 1.0 Double Height.png`
- Generated forms: `protracker-1p0.bin` and `protracker-1p0-double-height.bin`

The BZRPlayer project granted the Replay/Retrovert project permission to use, modify, and
redistribute the source faces and generated bitmap forms in the `retrovert-player`
repository and in shipped products.

Redistributions identify BZRPlayer as the source of these faces. This permission is a
specific grant for the named font resources; it is separate from the GPL-3.0 license that
covers the BZRPlayer repository as a whole.

The Replay/Retrovert project owner's written confirmation of the grant is recorded in
FPGAArcade/replay_frontend issue 623, “Choose Player UI licensing and font policy.”
