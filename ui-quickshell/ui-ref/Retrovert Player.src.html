2Demoscene / game music focus · two modes

Library is reorganised around what tracker and chip music actually carries: format (MOD, XM, IT, SID, SPC, VGM, AHX, NSF), channel count, composer and group, year, subsongs, and the sample/instrument list and message stored in the file. 2a evolves 1a into the browsing mode; 2b is the hero mode from 1b: pattern scroller, per-channel scopes, order list and samples, meant for fullscreen (super+f). The pattern and scopes animate.
